# Yashika Mahajan Portfolio

Humanist-futurist, multi-page portfolio site for Yashika Mahajan. Built with static HTML/CSS and minimal JS, designed to showcase consulting work, projects, impact, and writing.

## Local Preview

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000 in your browser.

## Structure

- `index.html` - Home
- `about.html` - About + learnings
- `experience.html` - Experience + internships
- `projects.html` - Projects + ongoing placeholder
- `impact.html` - Achievements + leadership + community impact
- `l5ai.html` - Case study (Zendesk+ClickUp AI at L5.ai)
- `blog/` - Blog listing + draft posts
- `contact.html` - Contact details
- `assets/` - CSS, JS, images, and resume PDF

## Update Content

- Replace `assets/img/portrait-placeholder.svg` with a real headshot.
- Update `projects.html` with live project details.
- Replace draft blog posts in `blog/` with final writing.

## Deploy (GitHub Pages)

1. Push the repo to GitHub.
2. In GitHub: Settings -> Pages -> Source: `main` branch, `/ (root)`.
3. Save. Your site will be available at:
   `https://yashikamahajanbiz.github.io/YASHIKA-MAHAJAN_portfolio/`
